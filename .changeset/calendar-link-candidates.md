`meetingLinkCandidates` drops a sentence's closing stops from an address in one pass from its end, so an address that holds a long run of stops is read in time linear in its length. An address written out ends at a control character, as it ends at a reference to one. It also ends at any character past ASCII, such as a curly quote, an ideographic comma or an emoji, which neither Meet nor Teams writes in its addresses. The README states that `readEvent` sends no query and names the `@framers/agentos-ext-account-sources` peer floor the package declares, 0.7.3.
