A public-source library for citation checks: `PublicSourceProvider`, English Wikipedia's provider (REST search by topic phrase, page HTML by key, reference markers removed, one limiter with Retry-After, the policy's User-Agent, size caps and a deadline) and `citationSources(document, cut)`, with CC BY-SA 4.0 on every passage.
