Fix ten defects in support requests. `systemMessage` refuses the package's own keys with a `TypeError`, so a product event never rings the identity opening's bell. The hourly sweep resolves a request the product opened with system messages alone seven days after its newest system message, and the close step closes it 30 days later, so it ends as every request does instead of waiting on the person. `open` answers once its write commits and the bell has rung, and the team alert's mail goes behind the answer with its failure line kept, so a slow mail hook holds no answer. `useStream` holds the events that arrive behind a hidden page and hands them on in order when the page shows again, acknowledging the newest message among them once, so a reply the person saw on coming back is not mailed and a page that refreshes from `onEvent` never marks read a reply nobody saw; a newer held state replaces an older one, and a new connection for the same request asks for the held events again. A person holds at most 20 unattached uploads within the hour the sweep keeps them (the new `picturesUnattachedMax` limit), and the next is refused `429 upload_quota` before it is decoded. A new migration, `0002_partial_indexes.sql`, adds partial indexes for the owed mail rows, the messages whose bell is unmarked with attempts left, and a person's unattached uploads, which the minute tick and the upload bound read. A subject or a body of control characters alone is refused, since the text is checked as it is stored. A staff reply on a resolved request reopens it with its `reopened` system message, so the close step never closes the thread under the question. A closed request marked resolved carries no close time.
