`EmailService` gains a read surface for a host that files the mail a mailbox receives. `readInbox` also takes one object, `{ folder, limit, afterUid, uidValidity, maxBytes, authServId }`: with `afterUid` it gives the first `limit` messages whose UID is greater, oldest first, whatever their flags, searching `UID <afterUid + 1>:*` and leaving out the last message such a range names when its UID is not greater; given `uidValidity` beside it, a folder whose UIDVALIDITY is another is read from its first message, since its UIDs were given anew; a FETCH response the server sends unasked during a read, such as the flags another session changed, is no message of it. Each message `readInbox` and `searchEmails` give gains `uidValidity` (the folder's, which a cursor keeps beside the UID), `key` (the EMAILID where the server offers OBJECTID, else Gmail's X-GM-MSGID where it offers X-GM-EXT-1, else the folder and the Message-ID, which a sender writes), `recipients` (every To, Cc and Delivered-To address, in lowercase, a local part in quotes only where RFC 5322 needs them), `inReplyTo`, `references`, `autoSubmitted`, `precedence`, `autoreply`, `isReport`, `authentication` (`dkim`, `spf`, `dmarc`, `dmarcFrom`, the domain the DMARC result names, and `alignedDomain`, `none` when the From names no domain, from the first Authentication-Results field, or the first that names `authServId`, which a decision that trusts the results gives), `text` and `html` (the text parts, and the HTML parts, joined in order when a picture splits them, of an alternative's forms the first, bounded by `maxBytes`, 262,144 by default) with `truncated`, and `attachments`, whose bytes only `read(maxBytes)` fetches. `readHeaderFields` and `parseAuthenticationResults` read the same fields from a header block a host fetched another way.

`moveTo`, `addLabel` (Gmail's X-GM-LABELS where offered, else a copy into the folder), `setFlags` (a keyword in the spelling the folder's PERMANENTFLAGS keep, matched ignoring case) and `deleteMessage` (the `\Deleted` flag and `UID EXPUNGE`) act on one message by UID and reject with `EmailMailboxError`, whose `code` is `gone` when the folder holds no message with that UID, before any other answer, and when another session expunges the message between the search for it and the change. `emailRead` and `emailSearch` answer plain data: no HTML part and no `read()`; `emailRead` refuses a folder that is not text. Nothing of the send side changes.
