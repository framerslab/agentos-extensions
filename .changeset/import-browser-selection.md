Add browser selection adapters for the import walker, under `src/import/browser.ts`, typed by the structure they call so the pack still compiles without DOM types. `fileRoots` takes a multiple-file input, keeping files that share a name apart. `relativeFileRoots` rebuilds a directory input's folders from each file's relative path, refuses an unsafe, repeated or missing path, and claims no folder that no returned file names. `captureDrop` asks every dropped file item for its file-system handle, entry and file inside the drop event, before its first wait, then reads each directory through its handle or through its entry reader, drained through the empty batch; a directory whose provider failed is never read as an apparent empty file, and every refusal comes through its promise. `chooseDirectory` opens the read-only directory picker and answers `selected`, `cancelled`, `unsupported` or `failed`. A file's body is read only after review, in 65,536-byte slices, one at a time; a short read is refused, a provider's error becomes a fixed code, and an aborted signal ends a browser call still pending. No package entry exports it yet; the existing entries are unchanged.
